# Скрипт сборки исходных файлов (POSIX Shell)

Простой скрипт на базе стандарта POSIX Shell для сборки программ (C, C++) и документов (LaTeX).

---

## Возможности

* **Универсальность:** поддержка исходников C (`.c`), C++ (`.cpp`, `.cxx`, `.cc`) и документов TeX (`.tex`).
* **Определение выходного имени:** имя целевого файла извлекается автоматически из комментария вида `Output: <имя_файла>`.
* **Изолированная сборка:** процесс компиляции происходит во временном каталоге (`mktemp`).
* **Автоматическая очистка:** временный каталог и промежуточные артефакты удаляются при любом завершении работы (включая сигналы прерывания через `trap`).
* **Информативные коды возврата:** скрипт возвращает понятный статус ошибки при сбое.
